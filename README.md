# Atlas de Erosión Democrática

Atlas interactivo de literatura sobre erosión democrática.

## Sitio web
El repositorio está preparado para GitHub Pages desde la rama `main` y la raíz `/`.

## Cobertura
- 23.525 trabajos.
- 79.136 relaciones internas de citación.
- Navegación por umbral de citas, referencias/citantes, profundidad y autor.
- Búsqueda y ficha bibliográfica.
- Diseño responsive para computador y teléfono.

## Nota técnica
La versión web conserva la red completa y los metadatos bibliográficos esenciales. Para mantener una carga viable en GitHub Pages, el payload se divide en fragmentos comprimidos externos y se omiten del despliegue algunos campos de texto pesado, especialmente abstracts, familias, clusters, tags y queries. El paquete fuente original conserva esos campos.
